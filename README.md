# BCTC-Server-Setup
### Download Files
* Click the release at the right side that says v1.0.6
* Download the httpd zip file and the PHPinstall.ps1 file
* Right click the zip file
* Click properties
* Check the unblock checkbox
* Click Apply and Ok
* Do the same for PHPinstall.ps1
### Run the install script
* Right click on PHPinstall.ps1
* Click copy path
* Open powershell
* Type . and then paste by right clicking in the terminal
* Type in version 8.5
* Type x64
* Type true
* Type UTC
* Type 1
### Test the install
* Open a brand new terminal and type 'php -v'
